# 8-Ball Discord Bot

A simple Discord bot that answers questions like a magic 8-ball. Built using Node.js and Discord.js, this bot responds to user queries with random, fun answers.

---

## Features

- Responds to user questions in Discord channels
- Provides randomized 8-ball style answers
- Easy to configure and run locally
- Lightweight and efficient

---

## Installation

1. Clone the repository:

```bash
git clone https://github.com/tmv-js/8ball_DiscordBot.git
cd 8ball_DiscordBot
````

2. Install dependencies:

```bash
npm install
```

3. Create a `.env` file in the root directory and add your Discord bot token:

```env
DISCORD_TOKEN=your-bot-token-here
```

> **Note:** Never commit your `.env` file or bot token to GitHub.

---

## Usage

Start the bot with:

```bash
node index.js
```

Once the bot is online, you can ask it questions in your Discord server, and it will respond with a random 8-ball answer.
